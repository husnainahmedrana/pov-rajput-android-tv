# POV Rajput 0.3.28

## New

- **Language flags on links.** Every audio language a link names now shows as its own badge with a flag and a short code, e.g. "🇬🇧 ENG", "🇮🇳 HIN", "🇫🇷 FRA". Your audio language comes first, then up to three others ("+2" when there are more). Hindi, Tamil and Telugu share a flag, so the code tells them apart. The flags show whether or not you have set preferred languages.
- **Subtitles in your language** show as "ENG SUBS" (no flag: flags are for audio only).

## Changed

- **The Elite badge style is gone.** Badge styles are Color by type (the default), Aurora and Sunset, all with the new flags. If you used Elite, your links switch to Color by type.
