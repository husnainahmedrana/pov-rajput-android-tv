# POV Rajput 0.3.23

## New

- **StreamNZB library.** The Library tab shows the releases your StreamNZB server has kept, newest first. Sign in once with your StreamNZB dashboard login; only the sign-in token is kept on the device. Select a release to play it.
- **AltMount library.** The Library tab shows the files AltMount has imported, newest first, and plays them straight from AltMount. Connect it once with AltMount's WebDAV login.
- **Library in Link sorting.** Library is now a row in Link sorting, like Language: on top by default, with First or Off, and it can be moved up or down. Links already in your AIOStreams, StreamNZB or AltMount library get an In library badge. This replaces the separate Library links first switch.

## Improved

- **Faster Home scrolling.** Holding Up or Down on Home moves through the rows faster, and the row you leave no longer slides over the artwork at the top.

Connect or disconnect the StreamNZB and AltMount libraries in the Library tab, or by holding OK on the add-on in Settings → Source providers.
